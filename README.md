# BridgingMod for Horizon

Reach-around placement ("bridge assist") for Horizon (Minecraft Java 26.3), a port of
[squeeglii's BridgingMod](https://github.com/squeeglii/BridgingMod) (MIT) to the Horizon mod SDK.

Right-click with a block while the crosshair hits nothing and the gap you are looking into gets the block, so a
bridge can be built over an edge without aiming at a face. A chevron at the crosshair shows which way it goes.

A Horizon native mod (`.hmod`): the launcher compiles it against its own game build. Replaces the retired `.hnmod`
mixin bundle; settings and the comma toggle carry over.

Source: https://github.com/xiryuudev/bridgingMod-horizon
